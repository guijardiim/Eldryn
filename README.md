## 🏰 Sobre o projeto

**Eldryn** é um jogo de RPG 2D desenvolvido como projeto acadêmico do curso de Ciência da Computação do UNISAGRADO.

O jogador assume o papel de um cavaleiro que precisa enfrentar goblins que ameaçam a tranquilidade de uma cidade. Durante sua jornada, deverá combater inimigos, explorar o ambiente e interagir com personagens do mundo do jogo.

Com uma estética inspirada em jogos clássicos de RPG em pixel art, Eldryn busca proporcionar uma experiência simples, envolvente e nostálgica.

## 🎮 Funcionalidades

- ⚔️ Sistema de combate contra inimigos.
- 🛡️ Personagem principal com movimentação e animações.
- 👾 Inimigos.

## 🚀 Como executar o projeto

### Executar pelo Unity

1. Clone este repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra o Unity Hub.
3. Selecione a opção **Add Project from Disk**.
4. Escolha a pasta do projeto clonado.
5. Abra o projeto utilizando a versão Unity 6000.6.0f1.
6. Abra a cena `MainMenu`.
7. Clique em Play para iniciar a experiência.

### Baixar e executar o jogo

Para jogar sem precisar abrir a Unity:

1. Acesse a seção **Releases** deste repositório.
2. Baixe a versão mais recente do Eldryn para Windows.
3. Extraia os arquivos, caso estejam compactados.
4. Execute o arquivo.

**Observação:** mantenha o executável e a pasta de dados gerada pela Unity juntos para garantir o funcionamento correto do jogo.
